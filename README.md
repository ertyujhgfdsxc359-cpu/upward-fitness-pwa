# 向上 · 我的健身记录

一款可以安装到手机或电脑的离线优先健身记录 PWA，用于记录训练、三餐、身体数据、目标与每日能量收支。

## 使用

通过 HTTPS 访问网页后，点击页面顶部的安装按钮，或从浏览器菜单中选择“安装应用 / 添加到主屏幕”。首次打开后，应用主体可离线使用。

所有个人记录默认只保存在当前设备的浏览器中。请定期使用页面内的“导出”功能备份数据；不同设备之间不会自动同步。

## 本地预览

PWA 的离线缓存需要通过 `http://localhost` 或 HTTPS 访问。直接双击 `index.html` 时仍可使用页面，但不会注册离线缓存。

## 发布

仓库可以直接通过 GitHub Pages 发布，入口文件为根目录的 `index.html`。
